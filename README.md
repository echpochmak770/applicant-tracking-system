# ATS (Applicant Tracking System)

Современная система управления процессом подбора персонала, ориентированная на масштабируемость, расширяемость и прозрачность бизнес-логики. Проект реализован с акцентом на практическое применение в HR-процессах и корпоративной среде.

---

## 🚀 Стек технологий

### Backend
* Platform: .NET 10  
* Framework: ASP.NET Core Web API  
* ORM: Entity Framework Core (Code First)  
* Database: Microsoft SQL Server  
* Architecture: Clean Architecture + CQRS  
* Security: JWT (Access/Refresh Tokens в HttpOnly Cookies), хеширование паролей  
* Дополнительно: динамическая фильтрация и сортировка через Expression Trees  

### Frontend
* Framework: React (SPA)  
* Build tool: Vite  
* Routing: React Router  
* UI: shadcn/ui  
* Data Grid: AG Grid  
* Drag & Drop: dnd-kit  
* Forms: React Hook Form + Zod  
* Input masking: react-imask  
* HTTP: Axios с интерцепторами (обработка 401/refresh token)

---

## 🏗 Архитектура проекта

Проект построен по принципам чистой архитектуры с разделением на логические слои:

* Domain Layer  
  Содержит основные сущности системы, перечисления и интерфейсы.  
  Это независимое ядро, не зависящее от инфраструктуры.

* Application Layer  
  Реализует бизнес-логику и сценарии использования.  
  Использует подход CQRS (разделение команд и запросов).

* Infrastructure Layer  
  Отвечает за доступ к данным, работу с базой данных, реализацию репозиториев и сервисов аутентификации.

* Presentation Layer (Web API)  
  Точка входа в систему. Содержит контроллеры, middleware и конфигурацию зависимостей.

---

## 🌟 Ключевые особенности

* Гибкая система фильтрации  
  Поддержка сложных запросов с динамической генерацией SQL (фильтрация, сортировка, пагинация).

* Управление вакансиями  
  Поддержка жизненного цикла вакансий с бизнес-ориентированной логикой статусов.

* Безопасная аутентификация  
  Разделение сценариев ошибок:
  * 400 — ошибки ввода (логин/пароль)
  * 401 — проблемы с авторизацией (истёкший токен)

* Масштабируемая архитектура  
  Проект легко расширяется за счёт разделения слоёв и использования паттернов.

* Современный UI  
  Интерактивный интерфейс с таблицами, формами, валидацией и drag-and-drop.

## 🛠 Инструкция по запуску

### Предварительные требования
1. .NET 10 SDK
2. Docker Desktop
3. Любая IDE (Visual Studio / Rider / VS Code)
4. Node.js (для frontend)

---

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/your-username/ats-project.git
cd ats-project
```

### Шаг 2: Запуск базы данных
docker-compose up -d

### Шаг 3: Настройка конфигурации backend
"JwtSettings": {
  "Secret": "your-very-strong-secret-key-32-chars-minimum",
  "Issuer": "ATS.Backend",
  "Audience": "ATS.Frontend",
  "ExpirationMinutes": 15,
  "RefreshTokenExpirationDays": 7
}

### Шаг 4: Применение миграций
dotnet ef database update

### Шаг 5: Запуск backend
dotnet run

### Шаг 6: Запуск frontend
Перейдите в папку фронтенда:
cd client
npm install
npm run dev

Приложение будет доступно по адресу:
http://localhost:5173

## 📝 Разработка
Работа со списками (фильтрация, сортировка, пагинация)

Все списки работают через универсальный объект запроса.
Фильтры автоматически преобразуются в SQL-запросы.

Формы и валидация

Формы реализованы с использованием:

React Hook Form — управление состоянием
Zod — схема валидации

Это обеспечивает:

строгую типизацию
централизованную проверку данных
удобную интеграцию с UI
Работа с таблицами

AG Grid используется для:

отображения больших объемов данных
серверной сортировки и фильтрации
кастомных ячеек и действий
Drag & Drop

dnd-kit применяется для:

изменения порядка элементов
управления списками
улучшения UX при работе с данными
