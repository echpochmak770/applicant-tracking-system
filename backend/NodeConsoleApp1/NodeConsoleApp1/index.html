📚 5. История веб-технологий (разные виды списков)

📄 HTML (маркированный список ul)

  • 1991: Первая версия HTML от Тима Бернерса-Ли
  • 1995: HTML 2.0 — стандартизация
  • 1997: HTML 4.0 — отделение стилей
  • 2014: HTML5 — семантика, видео, аудио

🎨 CSS (нумерованный список ol)

  1. 1996: CSS Level 1 — базовые стили
  2. 1998: CSS Level 2 — позиционирование
  3. 2011: CSS3 — модули, анимации
  4. Сегодня: CSS4 (отдельные модули)

⚡ JavaScript (список определений dl)

1995:
Создан Бренданом Айком за 10 дней (Mocha → LiveScript → JavaScript)
1997:
ECMAScript 1 — стандартизация
2009:
ES5 — JSON, строгий режим
2015:
ES6 — классы, модули, стрелочные функции
